# Cube Shadow Area
What is the average area of the shadow of a cube? I first stumbled upon this problem in [3B1B's video](https://www.youtube.com/watch?v=ltLUadnCyi0&t=148s)

Here is the caveman's way of approaching this problem using python.

## Libraries used
- Pygame
- Numpy
- Scipy

## Usage
```
pip install -r requirements.txt
python3 main.py
```
